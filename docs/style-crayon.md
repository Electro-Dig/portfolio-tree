# 风格拆解：彩铅绘本（crayon）

参考：两张街景插画（一家书店的正立面、一家面包咖啡店的正立面）。下面把画面拆成可以落到网页上的规则，再说明 `crayon` 主题具体怎么做。

## 一、画面拆解

| 维度 | 观察 | 关键词 |
|---|---|---|
| 媒介 | 彩色铅笔 / 油画棒。平涂不涂满，笔触方向一致，留出纸的颗粒和白点；同一块颜色里深浅不匀 | 颗粒、排线、留白 |
| 线条 | 细、略抖、经常断开的铅笔线；轮廓常画两遍、彼此错开一点；线色不是黑，而是深绿、灰蓝、暖灰 | 抖、断、双线、彩色描边 |
| 配色 | 低饱和、偏灰的柔和色：雾蓝、墨绿、鼠尾草绿、原木黄、芥末黄；只用一两处番茄红点睛；大面积纸白 | 粉灰、留白、一点红 |
| 构图 | 正立面、平视、几乎没有透视；主体居中，四周大量留白；细节很多但都很小 | 平、静、留白 |
| 文字 | 手写的英文大小写混排、字母略歪；招牌上的中文圆润；说明小字字距拉开、颜色很浅 | 手写、轻 |
| 点缀 | 植物（棕榈、盆栽、垂下的藤）、小招牌、星星、格子垫 —— 让画面有“生活在里面”的感觉 | 植物、小物件 |

### 色板（从画面取色，略作统一）

| 名称 | 色值 | 用在 |
|---|---|---|
| 纸白 | `#fbfaf5` | 背景 |
| 墨绿 | `#2f5d50` | 大枝 1、描线 |
| 鼠尾草绿 | `#8fae8b` | 大枝 2、叶子 |
| 雾蓝 | `#7e93b8` | 大枝 3 |
| 芥末黄 | `#d6b04a` | 大枝 4、胶带 |
| 原木 | `#c69a6b` | 树干、根 |
| 番茄红 | `#d9573b` | 果实、印章（只在这里用） |
| 暖灰 | `#9a9890` | 卡片边线、说明小字 |

## 二、落到网页上（`crayon` 主题）

1. **纸**：去掉点阵，换成纸白底 + 很淡的纸纹颗粒（SVG 噪点）。
2. **树枝 = 彩铅涂色**：枝干不再是实心色带，而是用“斜向排线 + 白色颗粒”的纹理填充，不涂满；外面再用同色系更深的颜色描两遍细线，两遍错开、偶尔断开。
3. **树干 = 原木色**，根部用同样的彩铅笔触；地面换成几簇草的笔触。
4. **叶子**：沿着小枝长出小叶片（椭圆 + 一根叶脉），绿色系里夹一点芥末黄；“流动观看”时叶子跟着枝条一起长出来。
5. **果实**：番茄红彩铅圆，带一点白色高光。
6. **卡片**：白底、细的暖灰铅笔边，去掉硬阴影；胶带换成半透明的芥末黄 / 雾蓝色块。
7. **字**：作品名、分枝名换成手写感更强的楷体（优先用系统里的「霞鹜文楷 / 楷体」，没有就退回默认字体）；按钮仍用得意黑。
8. **克制**：红色只留给果实和印章；其余全部是低饱和色，和参考图一样“安静、留白多”。

切换：`content/content.js` 里 `site.theme: "crayon"`，或在网址后加 `?theme=crayon`。
